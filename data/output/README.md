# 복원된 영어 시험 문제지

2020년부터 2026년까지 고1, 고2, 고3 영어 시험을 원본 문제지와 답지에서 복원한 파일이다.

## 구성

- 고1: markdown 26개, 이미지 181개
- 고2: markdown 25개, 이미지 131개
- 고3: markdown 23개, 이미지 91개
- 합계: markdown 74개, 이미지 403개
- 파일 이름: YYYY_M<월>_H<학년>_restored.md, 월은 0으로 채우지 않는다. 예: 2020_M11_H1_restored.md
- 이미지 이름: YYYY_M<월>_H<학년>_<문항>_image.jpg, 한 문항에 이미지가 여러 개면 image2, image3 순으로 붙인다.

## 복원 형식

- 각 문항은 번호, 문항 지시문, 복원된 지문으로만 구성한다. 설명, 부록, 정답표는 넣지 않았다.
- 1번부터 17번은 선지를 포함한다. 원숫자 선지는 각자 줄에 둔다.
- 18번부터 45번은 선지를 넣지 않는다. 지문 속 원숫자와 괄호 구간 표기도 제거했다.
- 공유 지문은 각 문항 아래에 전부 반복했다.
- 25번 그래프 문항은 이미지 참조 뒤에 전사한 표를 두었다. 표가 없는 경우는 아래 알려진 문제점을 본다.
- 40번은 지문만 두고 요약문은 넣지 않는다.
- 36번과 37번 순서 배열 문항은 구간을 나누지 않고 지문 하나로 합쳤다.

- 2021_M3_H3 41번·42번: proper → limited (교정 지문 인용 "seems a limited perspective")
- 2021_M7_H3 41번·42번: rigidity → variability (교정 지문 인용 "immediacy and variability of content")
- 2022_M6_H1 30번: ignoring → envying (원문 에세이 "end up envying how other people live", 올림포스 해설 일치)
- 2022_M9_H1 41번·42번: encouraged → abandoned (변형문제 4곳 일치 "abandoned that habit")
- 2022_M11_H1 41번·42번: easier → more difficult (한줄해석 2곳 일치 "was more difficult than he'd anticipated")
- 2025_M7_H3 41번·42번: acceptable → unacceptable (한줄해석 "feel unacceptable", 최소 교체 반의어. incomprehensible 가능성도 있으나 unacceptable로 결정)

# 복원된 영어 시험 문제지

2020년부터 2026년까지 고1, 고2, 고3 영어 시험을 원본 문제지와 답지에서 복원한 파일이다.

## 구성

- 고1: markdown 26개, 이미지 181개
- 고2: markdown 25개, 이미지 131개
- 고3: markdown 23개, 이미지 91개
- 합계: markdown 74개, 이미지 403개
- 파일 이름: YYYY_M<월>_H<학년>_restored.md, 월은 0으로 채우지 않는다. 예: 2020_M11_H1_restored.md
- 이미지 이름: YYYY_M<월>_H<학년>_<문항>_image.jpg, 한 문항에 이미지가 여러 개면 image2, image3 순으로 붙인다.

## 복원 형식

- 각 문항은 번호, 문항 지시문, 복원된 지문으로만 구성한다. 설명, 부록, 정답표는 넣지 않았다.
- 1번부터 17번은 선지를 포함한다. 원숫자 선지는 각자 줄에 둔다.
- 18번부터 45번은 선지를 넣지 않는다. 지문 속 원숫자와 괄호 구간 표기도 제거했다.
- 공유 지문은 각 문항 아래에 전부 반복했다.
- 25번 그래프 문항은 이미지 참조 뒤에 전사한 표를 두었다. 표가 없는 경우는 아래 알려진 문제점을 본다.

## 알려진 문제점

확인되지 않은 내용은 추측으로 채우지 않았다. 아래 항목은 원본 문제지와 답지를 대조해 확인되는 항목부터 차례로 보완하면 된다.

### 1. 정답표가 없는 시험 11개

다음 시험은 영어 정답표를 확보하지 못해, 정답에 의존하는 복원이 적용되지 않았다. 순서 문항(36, 37번), 삽입 문항(38, 39번), 빈칸 채우기(31번부터 34번), 요약문(40번), 문법과 어휘 교정(29, 30, 42번)이 원문 상태로 남았거나 빈칸 표시로 남았다.

- 2022_M4_H3
- 2025_M3_H1, 2025_M3_H2, 2025_M3_H3
- 2025_M5_H3
- 2025_M6_H1, 2025_M6_H2
- 2025_M10_H1, 2025_M10_H2
- 2026_M9_H1, 2026_M9_H2

사유는 두 가지다. 앞의 9개 시험은 답지 PDF가 실제로는 HTML 문서이고, 안에 있는 링크가 다른 연도의 자료를 가리켜 답지로 쓸 수 없었다. 뒤의 2개 시험은 답지 PDF에 국어 과목 해설만 들어 있고 영어 정답표가 없다. 2026_M9에 대해 이전에 기록된 국어 정답 숫자는 영어 정답으로 쓰면 안 된다.

빈칸 표시(____.)가 남은 문항은 다음과 같다.

- 고1: 2025_M3 34번, 2025_M6 33번과 34번, 2025_M10 32번과 33번과 34번. 같은 세 시험의 40번 요약문 빈칸도 채우지 못했다.
- 고2: 2025_M3 32번과 34번, 2025_M6 31번, 2025_M10 32번과 33번과 34번. 같은 세 시험의 40번 요약문 빈칸도 채우지 못했다.
- 고3: 2022_M4, 2025_M3, 2025_M5의 29번, 30번, 42번 교정과 40번 요약문이 미복원 상태다.

예외로, 2026_M9_H1의 31번 빈칸은 단어가 이미 들어 있던 경우라 정리만 했고, 40번 한 구절은 문제지 선지와 지문의 정합으로 확인해 정정했다.

### 2. 그래프 표를 만들 수 없는 시험 4개

다음 25번 그래프는 막대나 꺾은선에 수치 표시가 없거나 범례가 잘려 있어, 정확한 표를 만들 수 없었다. 그래프 이미지는 배정했고, 수치를 추정해 표를 지어내지는 않았다.

- 2021_M3_H2 25번
- 2022_M3_H2 25번
- 2021_M3_H3 25번
- 2021_M7_H3 25번

그 외 70개 시험의 25번에는 전사한 표가 들어 있다.

### 3. 문법과 어휘 교정이 남은 경우

답지 해설이 한국어 설명 형태라서 옛 단어와 새 단어로 된 교체 쌍을 확정할 수 없거나, 42번 밑줄 단어가 대명사나 지시어군이라 단일 단어 교체로 확정할 수 없는 경우, 원문을 그대로 두었다. 고3의 경우 대명사군 42번 17건을 포함해 30건이 남았다.

### 4. 이미지를 배정하지 못한 경우 23건

빈 프레임이나 조각이라 특정 문항으로 확인할 수 없어, 임의로 배정하지 않았다. 고1 11건, 고2 6건, 고3 6건이다.

### 5. 고1 43번 그룹 순서 미재정렬

고1 43번 그룹 지문은 원본 텍스트만으로 구간 경계를 나눌 수 없어, 순서를 재정렬하지 않았다. 43번 지문은 44번, 45번 지문과 같고 서사 순서대로 두었다.
